# Campgroundless has moved

Campgroundless is now at **https://campgroundless.com**.

This repository only keeps the old `quadrinary.github.io/campgroundless` address working:

- every page redirects to the same path, query, and `#hash` on campgroundless.com;
- `site-config.json` is mirrored hourly from https://campgroundless.com/site-config.json, so older iPhone app builds still receive the current site policy.

The app's source code is private. Contact: support@campgroundless.com.
