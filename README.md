# Campgroundless

A responsive California public-land boundary explorer for dispersed-camping trip planning. This is a static site intended for GitHub Pages.

## What the map does—and does not do

- Displays selected federal, state, and local public land management/ownership records in California from the **Fee** feature class.
- Filters a public ArcGIS-hosted layer reproducing USGS PAD-US 3.0 data by California and manager category. The layer is queried live as the map is used; the ArcGIS hosting endpoint is outside USGS.
- Shows the mapped manager, unit name, PAD-US public-access attribute, and source date when available.
- Lets visitors attach browser-local notes/reviews and camping, travel, or landmark icons to clicked map locations. Clicking a managed-land polygon opens its information popup; select **Write note here** and choose an icon to open the note editor at that exact point. Each saved note can be shared with a view-only link containing a snapshot of that note; the link data is stored in its URL fragment, not uploaded, and anyone with the link can view it. Edits made after a link is created do not change that snapshot.
- Does **not** determine whether dispersed camping is allowed at a site. Public-land boundaries, public-access attributes, and manager names are not camping authorization. Closures, road access, permits, fire rules, stay limits, and local restrictions must be verified directly with the responsible office.

The web map uses the USGS PAD-US 3.0 land-ownership layer. PAD-US is a compiled inventory; data age, completeness, scale, and accuracy vary by source. The ArcGIS service metadata reports data last edited on May 23, 2023. California's PAD-US 3.0 update included state, regional, local, and nonprofit data from the California Protected Areas Database (CPAD), but the map filters to selected government managers and fee records. It is not a parcel-level legal boundary map, does not provide comprehensive or current camping permission, and a missing polygon is not evidence that land is private or unavailable. The newer PAD-US 4.1 release is available from USGS; this live map does not claim to use it.

Attribution is shown on the map.
- Optional U.S. Forest Service reference overlays: [Recreation Opportunities](https://apps.fs.usda.gov/arcx/rest/services/EDW/EDW_RecreationOpportunities_01/MapServer) (service says updated nightly), [National Forest System Roads](https://apps.fs.usda.gov/arcx/rest/services/EDW/EDW_RoadBasic_01/MapServer) (service says road data is updated daily), [National Forest System Trails](https://apps.fs.usda.gov/arcx/rest/services/EDW/EDW_TrailNFSPublish_01/MapServer) (trail attribute completeness varies by forest), and [Motor Vehicle Use Map (MVUM) routes](https://apps.fs.usda.gov/arcx/rest/services/EDW/EDW_MVUM_01/MapServer). When enabled, the MVUM overlay includes the Forest Service's own road/trail symbol legend, including vehicle types and seasonal designations. The MVUM route service depicts designated motor-vehicle use and seasonal vehicle restrictions, but its coverage is not complete for every forest and data is refreshed unit by unit as approved; check the current official MVUM for the specific forest. A separately toggleable roads sublayer shows roads mapped as closed to motorized uses. These are operational reference data, not real-time access, closure, or camping-permission feeds; verify current conditions with the responsible Forest Service office.
- Optional BLM National Ground Transportation Linear Features (GTLF) motorized road datasets: [Public Motorized Roads](https://www.arcgis.com/home/item.html?id=f94999eb674d4085be0c86729fe4a151) and [Limited Public Motorized Roads](https://www.arcgis.com/home/item.html?id=4a2d788c46804bfbb7288d05184e2936). The map filters the national services to California's `ADMIN_ST = 'CA'` features. Its legend uses solid green and dashed rust lines to distinguish the public-release dataset subsets; the names do not confirm that a particular road is legally accessible to the public, currently open, or suitable for a vehicle. These GTLF datasets include transportation line features and not just roads. Verify route designations and current access with the responsible BLM office.
- Nearest named-road reference: [U.S. Census Bureau TIGERweb Transportation](https://tigerweb.geo.census.gov/arcgis/rest/services/TIGERweb/Transportation/MapServer), using primary, secondary, and local named roads (service metadata dated January 1, 2026). Clicking a mapped USFS/BLM road looks up the nearest named Census road within 10 km and reports straight-line distance, not driving distance. Road hit tolerance adapts to map zoom (about 12 screen pixels, bounded to 35–400 m); zoom in for precise selection, since a nearby route may match at low zoom. Census road names and classifications are a reference and do not confirm local jurisdiction, public access, or current conditions.
- Place search: [OpenStreetMap Nominatim](https://nominatim.openstreetmap.org/) search service and [usage policy](https://operations.osmfoundation.org/policies/nominatim/). Place results are limited to California, attributed to OpenStreetMap, and requested only after the user submits a search; there is no autocomplete. Repeated searches are cached in memory for the page session, and this browser waits at least one second between uncached requests. Do not submit personal or confidential information. The public Nominatim service has a strict maximum of one request per second per application; if traffic grows beyond a modest level, use a provider or shared proxy with compliant global rate limiting and caching.

The app uses Leaflet and Esri Leaflet from unpkg.com. It is a static client-side site; the browser contacts the map/data providers directly.

## Map settings and API keys

Open **Settings** from the map navigation to select USGS PAD-US 3.0 or a custom PAD-US-compatible ArcGIS Feature Layer, toggle manager categories, choose Esri, USGS, OpenStreetMap, or custom XYZ basemaps, select an OpenStreetMap rendering style when that basemap is active, enter optional provider keys, set custom source attribution, and change the Nominatim-compatible place-search endpoint. The map’s **Layers** button above the zoom controls also selects the basemap and toggles optional USFS recreation, roads, motorized-road-closure, trails, MVUM routes, and BLM GTLF road dataset overlays. Each enabled reference overlay shows its own symbol legend directly below that overlay’s control. Clicking a mapped USFS/BLM road retrieves available route restrictions, nearby PAD-US land attributes, coordinates, and the straight-line distance to the nearest named primary, secondary, or local road in Census TIGERweb (searched up to 10 km). This lookup is for reference only: names, route data, land coverage, and restrictions can be incomplete or outdated, and a named road or mapped route does not establish public access or camping permission. Reference overlays are off by default and load only when selected. MVUM legend entries explain designated vehicle types and seasonal access; BLM legend lines identify source dataset subsets. Verify current rules with the land manager. Map imagery, roads, trails, recreation sites, and mapped closures are not authoritative proof of current access or camping rules. OpenStreetMap choices have independent providers, availability, attribution, and usage terms. Custom land services must expose the fields and manager codes used by PAD-US (`FID`, `State_Nm`, `FeatClass`, `Mang_Name`, `Unit_Nm`, `Loc_Nm`, `Pub_Access`, and `Src_Date`) because the map filters and popups rely on that schema. Custom place-search endpoints must use HTTPS and return a Nominatim-compatible JSON array with `lat`, `lon`, and `display_name` fields.

Settings also provide three interface text-size sliders with 1 px increments and a ±5 px range around each default: body text and field labels (7–17 px, default 12 px), search/map status/source text (6–16 px, default 11 px), and small captions/toolbar notes (5–15 px, default 10 px). These preferences preview immediately and are saved with other browser-local settings.

Preferences and API keys are stored in that browser's `localStorage` and are not uploaded to this site. Map requests send a key only to the selected data or tile provider. A browser-stored key is accessible to people with access to the browser and is visible in outgoing requests; never save a private server secret here. Use provider-restricted, low-privilege keys. Esri/OpenStreetMap defaults work without keys.

Map notes and their selected icons are saved in browser storage only; they are not uploaded or synchronized. Clearing this browser's site data removes them. A share link contains the selected note's title, text, icon, and coordinates in its fragment. Anyone with the link can read that snapshot, and URL contents may be visible in browser history or wherever the link is forwarded. Shared notes are view-only, do not alter the recipient's saved notes, and do not confirm camping permission. Do not enter sensitive information.

The data and basemap selections apply on the map page. Land-manager filters and reference overlays save when changed from the map; overlay preferences are per browser/device, off by default, and can be reset with the other settings.

## Local development

Open `index.html` in a modern browser or serve this folder with any static HTTP server. No build step or package installation is required.

## Hosting on GitHub Pages

The workflow in `.github/workflows/pages.yml` publishes the repository root to GitHub Pages whenever changes are pushed to `main`, or when manually started. GitHub Pages must be enabled for the repository with **GitHub Actions** as its build and deployment source.
