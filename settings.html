YOUR MAP, YOUR SOURCES

Map settings.

Choose which land records and basemap to show. Settings apply to this browser and are not synced across devices.

01

Land data source

Choose the ArcGIS Feature Layer used for mapped land boundaries.

Select a land data source

Enter one ArcGIS Feature Layer endpoint over HTTPS, including its layer number. It must provide PAD-US-compatible fields and coding, including FID and the manager codes this map filters.

Shown in the map attribution control. Check the data provider's attribution requirements.

Sent only with requests to the selected ArcGIS land-data service.

02

Land-manager layers

Choose which categories to display. Every category represents land management—not camping permission.

These filters are also available in the map sidebar. Changes are saved for this browser only.

03

Recreation-site visibility

Set one minimum zoom level for both USFS and BLM recreation sites.

The Forest Service service hides sites beyond about 1:400,000 scale. This setting makes BLM visibility match USFS and can require a closer zoom, but cannot make USFS sites appear beyond the service limit. Lower zoom numbers show sites farther out.

04

Basemap

Choose the background map. Tiles are loaded directly from the selected provider.

These are alternative map renderings, not separate land or trail data layers. Tile availability and terms vary by provider; avoid bulk downloads. OpenStreetMap tile usage policy

Must include {z}, {x}, and {y} placeholders. Use {apiKey} where the provider expects the key; otherwise it will be added as a query parameter.

Shown in the map attribution control. Follow the tile provider's terms.

Added to Esri tile requests if you select the Esri basemap.

Used only for the custom XYZ tile service.

05

Place search provider

Searches use this provider when a query does not match a loaded land unit.

Default: OpenStreetMap Nominatim. You may switch to another HTTPS Nominatim-compatible endpoint here without an app update. The endpoint must return a JSON array with lat, lon, and display_name fields. Queries are sent only when you press Go; do not submit personal or confidential information.

06

Text size

Adjust the map interface text. Changes preview as you select them and are saved with your settings.

07

Appearance & map clicks

Choose a day or night look. Auto follows your device's light/dark setting. Changes preview immediately and are saved with your settings.

08

Map notice

Control the reminder strip shown below the map.

09

Stored data

Space used by data kept in this browser. Map layers and basemap tiles are loaded live and are not stored by this app.

    About API keys in a static website

    Keys are stored in this browser's local storage, not on a server or in an account. They are sent to the provider you choose and can be read by anyone with access to this browser. Use provider-restricted, low-privilege keys; never enter a private server secret. Clear the key here or reset settings to remove it.
